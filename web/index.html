Your codebase,
one clean context file.

ContextPress folds your project into a single Markdown capsule that your AI assistant can read in one paste. It honors your .gitignore, skips binaries, and tells you the token cost before you send anything.

Try the CLI

or drop a folder anywhere on this page

01

Respects .gitignore

Secrets, build output, and dependency folders stay out automatically. Add your own patterns if something else needs to be hidden.

02

Readable structure

The capsule opens with a directory tree, so the model sees how your project fits together before it reads a single line of code.

03

Token aware

File count, total size, and an estimated token count help you judge whether the context fits your model window.

Prefer the terminal?

The same tool ships as a single Python file. No install, no dependencies.

python context_press.py

That reads the current directory and writes codebase_context.md next to it.

python context_press.py ./my-project -o capsule.md
python context_press.py -i "secrets/" "*.log"
python context_press.py --list
python context_press.py --serve
